🗄️ تحديث قاعدة بيانات Supabase — بأجزاء صغيرة

الطريقة: افتح Supabase → مشروعك → SQL Editor → + New query (نافذة جديدة فاضية — امسح أي نص قديم فيها). بعدها شغّل الأجزاء الخمسة تحت بالترتيب: اضغط زر النسخ → اضغط مطولاً بمحرر SQL → لصق → Run → لازم تطلع خضرا Success → بعدها الجزء اللي بعده.
1نظام البطاقات v1 — الحالة الحرجة ورمز الفرصة السري20KB
✅ اننسخ — الصقه بمحرر SQL واضغط Run
بعد اللصق اسحب لآخر النص وتأكد أن آخر سطر هو:
-- سجلاً تاريخياً؛ الجديدة تُعالج بـ brc.run_auto_release() المحذَّثة (حالة حرجة).
2دفعات البطاقات الفارغة والباركودات العشوائية9KB
✅ اننسخ — الصقه بمحرر SQL واضغط Run
بعد اللصق اسحب لآخر النص وتأكد أن آخر سطر هو:
-- الفارغة الجديدة تُدرج بـ status='blank' و issue_date=null من الواجهة.
3بيع نقطة البيع باختيار الوظيفة + صفحة صاحب العمل ★ الأهم12KB
✅ اننسخ — الصقه بمحرر SQL واضغط Run
بعد اللصق اسحب لآخر النص وتأكد أن آخر سطر هو:
grant execute on function brc.employer_decide(text, text) to anon, authenticated;
4طلب صاحب العمل (توظيف/عدم توظيف) وقرار الشركة13KB
✅ اننسخ — الصقه بمحرر SQL واضغط Run
بعد اللصق اسحب لآخر النص وتأكد أن آخر سطر هو:
'استمارة منتهية الصلاحية (30 يوماً)' يسبقها where f.status = 'expired';
5إعادة تحميل ذاكرة المخطط (سطر واحد)
✅ اننسخ — الصقه واضغط Run وخلصنا
آخر سطر بعد اللصق لازم يكون:
notify pgrst, 'reload schema';

كل الأجزاء آمنة للإعادة أي عدد مرات («إن لم توجد / استبدل إن وجدت») ولا تمس بيانات الزبائن — إذا فشل جزء في منتصفه، أعِد ضغط زره ولصقه من جديد ثم Run. إذا استمر خطأ أحمر: صوّره وابعثه.
