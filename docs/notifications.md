# مركز إشعارات الموظفين — 2026-10-18

## السلوك

- جرس داخل لوحة الموظفين، عدّاد غير المقروء، ودرج إشعارات بتصنيفات: الكل، غير المقروء، قرارات أصحاب العمل، والحجوزات.
- يعرض آخر **100** تحديث من البيانات والسجلات المتاحة للحساب، بترتيب وقت الحدث الأصلي. ليس أرشيفاً مستقلاً لكل تاريخ الموقع.
- الحجز من `job_attempts.selectedAt`، وقرار صاحب العمل من `employerDecision/decisionAt/reason`. «تم التوظيف» من صاحب العمل **طلب بانتظار تثبيت الشركة**، وليس توظيفاً نهائياً. عدم التوظيف يعرض السبب ولا يحرّر الوظيفة تلقائياً.
- قرارات الشركة النهائية، الحالات الحرجة، وتحديثات الوظائف والبطاقات من المحاولات وسجل التدقيق؛ آخر حالة وظيفة من `updated_at`/`created_at` عند غياب سجل مطابق. لا يُختلق وقت حالي للأحداث ذات التاريخ غير الصالح.
- العمليات المتطابقة في المحاولة والتدقيق تُدمج لتجنب تكرار القرار/الحجز. إشعار منبثق واحد للقرار الجديد أثناء الجلسة، بلا إغراق عند تحميل السجلات القديمة أو إعادة الرسم.
- «عرض التفاصيل» يفتح صفحات/نوافذ لوحة التحكم القائمة، ولا ينفّذ أي قرار أو تغيير حالة بذاته.

## الأمان والخصوصية

- الملفات الجديدة محمّلة في لوحة الموظفين فقط؛ لا تُضاف إلى صفحتي الزائر والتحقق. تضمّن نسخ العرض المستقلة نفس الواجهة مع بيانات عرضها المعتادة.
- المصدر هو `HRCStore` ومزامنته/اشتراكاته القائمة. **لا طلبات قاعدة إضافية، ولا جداول، ولا تعديل صلاحيات أو بيانات إنتاج أو دوال قرار.** أضيفت قراءة `updated_at` الموجودة في صف الوظيفة إلى التحويل المحلي فقط؛ لا تُكتب من المتصفح.
- لا قراءة للبيانات دون جلسة موظف؛ خروج/تبديل الحساب يغلق الدرج ويمسح نصوصه وإعلانه المقروء آلياً. التحديثات الإدارية للحسابات/الإعدادات/النسخ للمدير فقط. سجلات بطاقات الزملاء لا تمنح الموظف صلاحية جديدة: تظهر له عملياته والسجلات النظامية المتاحة؛ بيانات قرارات/حجوزات الوظائف ضمن صلاحية العمل الحالية.
- نصوص العناوين والأسباب والسجلات تُهرب قبل HTML. لا تُسقط رموز الفرص أو PIN أو بيانات المصادقة ضمن نموذج الإشعار.
- حالة القراءة **محلية لكل مشروع/حساب/دور/جهاز**، وليست مشتركة بين الأجهزة. يُحفظ آخر 600 معرّف مقروء بصيغة SHA-256 ذات نطاق حساب/مشروع، لا محتوى الإشعار ولا رقم البطاقة الخام. عند غياب التشفير تبقى القراءة في ذاكرة الجلسة ولا تُحفظ معرّفات خام.
- هذه إشعارات **داخل الموقع** عند فتح اللوحة ومزامنتها؛ ليست Push للهاتف أو خدمة تعمل بعد إغلاق المتصفح. حالة الاتصال موضحة في الدرج، ولا تُعرض البيانات القديمة على أنها اتصال مباشر.

## التنسيق والتحقق

- عناوين الوظائف تأخذ مساحة حقيقية، وشارات الحالة/التصنيف تلتف كسطر منفصل عند الحاجة، ونطاق الراتب يمتد بعرض البطاقة. أزرار التذييل تلتف ولا تزاحم الراتب.
- بطاقات الإحصائيات تتكيف مع عرضها والأرقام الكبيرة، والقيمة المالية لها صف كامل. الجداول الداخلية تحافظ على كلمات عربية مقروءة مع تمرير داخل حاوية الجدول، لا قص بياناتها.
- درج الإشعارات يدعم Escape، حصر/إرجاع التركيز، خلفية inert، تقليل الحركة، تصفية كاملة دون قص أزرار الموبايل، وعدم الظهور في الطباعة.
- `npm run test:notifications`: 32 فحص إسقاط/ترتيب/إزالة تكرار/صلاحيات/عدم تسريب أو تعديل البيانات.
- `node tests/notifications-browser.mjs`: اختبار اختياري مع اعتماديات Chromium الموضحة في رأس الملف وخادم محلي 4173؛ 136 فحصاً على 320/375/768/1440. يشمل قراراً وسبباً يحوي HTML ضاراً، القراءة وإعادة التحميل وتبديل الحساب والخروج، الانتقال للتفاصيل، وأرقاماً طويلة وعناوين عربية فعلية. الشبكة الخارجية وعامل الخدمة معطّلان، ولا تُستخدم بيانات إنتاج.
- `node tests/visual-layout-browser.mjs`: 52 فحص تنسيق/طباعة/تقليل حركة. تستخدم الاختبارات Chromium بوضع GPU معطل لتجنب تعليق SwiftShader في بيئة الاختبار عند إعادة التحميل؛ هذا إعداد للاختبار فقط.
