## 2) آلية عمل النسخ الاحتياطي

### أنواع النسخ

| النوع | كيف يُنشأ | الصيغة |
|---|---|---|
| **سريعة** | زر «نسخة احتياطية سريعة» | نسخة كاملة في `localStorage` |
| **مجدولة** | نافذة «جدولة النسخ التلقائي» | كاملة أو بنطاق تاريخي (`partial`) |
| **تلقائية** | محرّك `checkAutoBackup` عند فتح اللوحة | تُنشأ مرة واحدة لكل (يوم + وقت) |
| **أمان** | تلقائياً **قبل كل استعادة** باسم «قبل الاستعادة» | كاملة |
| **ملف خارجي** | «تصدير JSON» | `brc-backup-YYYY-MM-DD.json` |

### مفاتيح التخزين في المتصفح

```
brc-scheduled-backups      → قائمة النسخ (الحد الأقصى 20 نسخة)
brc-auto-backup-schedule   → أيام الجدولة + الوقت
brc-auto-backup-last-run   → بصمة آخر خانة نُفّذت  (YYYY-MM-DDTHH:mm)
```

### أين ومتى تُنفَّذ الجدولة

المحرّك **لا يعمل بمؤقّت خلفي** (لا يوجد خادم) — بل يُفحَص:
- عند إقلاع اللوحة (`init`)
- كل 60 ثانية أثناء فتح اللوحة (`ticker`)

**الحماية من التكرار:** لكل (يوم + وقت) خانة واحدة. لو فُتحت اللوحة بعد الوقت
المجدول، تُلتقط النسخة الفائتة **مرة واحدة** ولا تُكرَّر عند إعادة الفحص.

### حالة تحقّق مثبتة بالنقر

| السيناريو | النتيجة |
|---|---|
| جدولة 08:00، اللوحة عند 07:59 | لا نسخة ✅ |
| جدولة 08:00، اللوحة عند 23:59 | نسخة واحدة `auto` ✅ |
| إعادة الفحص 23:59 مرة ثانية | لا تكرار ✅ |
| يوم غير مجدول | لا نسخة ✅ |
| 30 نسخة متتالية | يُحتفظ بـ 20، الأقدم تُسقَط ✅ |

## 3) الأزرار — نتيجة الفحص زر بزر

لوحة «النسخ الاحتياطي والصيانة» (الإعدادات ← على شكل نقر فعلي):

| الزر | المعرّف | النتيجة |
|---|---|---|
| نسخة احتياطية سريعة | `btn-quick-backup` | ✅ يحفظ نسخة + يحدّث العدّاد |
| تصدير JSON | `btn-export` | ✅ يُنزّل `brc-backup-YYYY-MM-DD.json` |
| استيراد نسخة | `btn-import` | ✅ يستورد / يرفض ملفاً تالفاً بأمان |
| جدولة النسخ التلقائي | `btn-schedule-backup` | ✅ نموذج 7 أيام + وقت |
| عرض النسخ الاحتياطية | `btn-view-backups` | ✅ قائمة + تصدير/استعادة/حذف |
| تشغيل قواعد الحجز | `btn-maintenance` | ✅ بلا أخطاء JS |
| إعادة ضبط البيانات | `btn-reset` | ✅ «تأكيد» يُنفّذ و«إلغاء» يُلغي |
| تعديل الجدولة | `btn-edit-schedule` | ✅ يفتح بالقيم المحفوظة |
| نفّذ نسخة الآن | `btn-run-auto-backup` | ✅ نسخة `auto` فورية |
| إيقاف الجدولة | `btn-disable-schedule` | ✅ يمسح الجدولة وآخر تنفيذ |
| نسخ رابط التحقق | `copy-url` (بطاقة الاستمارة و`verify.html`) | ✅ يستدعي الحافظة بالرابط الصحيح |

**نقطة مهمة تم إصلاحها سابقاً وتأكدنا منها:** نافذة التأكيد كانت تُرجع `false`
دائماً (بسبب `onClose`)، فأزرار «تأكيد الحذف» و«إعادة الضبط» لم تكن تعمل.
الآن مؤكَّدة تعمل.

**حاضر ضد الربط المكرر:** `bindOnce` يضمن أن نقرة واحدة = نسخة واحدة، حتى بعد
التنقل بين الصفحات أو إعادة الرسم — وهذا مُختبَر.

## 4) الأمان والحماية من فقدان البيانات

- **حماية امتلاء `localStorage`**: عند فشل الكتابة تُسقَط النسخ الأقدم واحدة واحدة
  ويُعاد المحاولة؛ إن فشل الكل تظهر رسالة «مساحة التخزين ممتلئة» ويُرجَع `null`
  بدل تعطيل الصفحة.
- **الاستعادة الجزئية دمج لا استبدال**: تدمج الاستمارات والمحاولات والسجلات
  مع إزالة التكرار (بالمفتاح التسلسلي) — لا تفقد بيانات الوظائف الأخرى.
- **نسخة أمان قبل كل استعادة**: لا يمكن أن تخسر الحالة الراهنة.
- **فشل آمن عند الاستيراد**: ملف تالف لا يمسح البيانات الحالية (مثبت بالاختبار).
- **تسجيل تدقيقي**: كل نسخ/حذف/استعادة/استيراد يُسجَّل في سجل التدقيق بالثانية.

## 6) ملاحظة خارج نطاق النسخ (موجودة مسبقاً)

`tests/audit.mjs` يفشل في فحصين، وليس لهما علاقة بالنسخ الاحتياطي:

```
brc-standalone.html — لا مراجع خارجية للموارد (صور/خطوط/كود)
brc-light.html      — لا مراجع خارجية للموارد (صور/خطوط/كود)
```

**السبب:** بيانات الوظائف التجريبية في `assets/js/config.js` تحتوي حقول `imageUrl`
تشير إلى `https://images.unsplash.com/...` (7 روابط)، وهذه الروابط تُدمج نصّاً داخل
الملف المستقل، فيكشفها فحص «لا مراجع خارجية».

**تأثيرها:** صور بطاقات الوظائف التجريبية لن تظهر بدون إنترنت في الملف المستقل
(النصوص والأيقونات والخطوط تعمل — الخطوط والصور المحلية مدمجة فعلاً).
**مطلوب قرار:** إمّا إسقاط `imageUrl` من البيانات التجريبية، أو تنزيل الصور محلياً
ودمجها، أو استثناء صور البيانات التجريبية من الفحص.

> ملاحظة: البناء **مطابق** للمصدر — `npm run build` لا يُنتج أي فرق عن الملفات
> الملتزمة (`brc-standalone.html`، `brc-light.html`).

## 7) ما أُضيف في هذا التحقق

`tests/backup.mjs` توسّع من 58 إلى **82** فحصاً، وأُضيف:

1. **جسر التنزيل**: jsdom لا ينفّذ `URL.createObjectURL`، فكان أي خلل في زر التصدير
   يمرّ صامتاً (مرشّح «Not implemented»). الآن يُلتقط التنزيل ويُتحقق من اسمه.
2. **جسر الحافظة**: للتحقق أن «نسخ الرابط» يُنادي الحافظة فعلاً وبالرابط الصحيح
   `/verify?form=<serial>&t=<token>` (المسار النظيف المدعوم في `_redirects` على Cloudflare Pages).
3. **الخطوة 8**: تغطية `btn-export` / `btn-import` (صالحة وتالفة) / `btn-maintenance`
   / `copy-url` / تأكيد إعادة الضبط — كانت **غير مغطاة بأي اختبار**.
4. **إصلاح فحص مضلّل**: كان فحص «التقاط النسخة الفائتة» يتحقق فقط من عدم التكرار
   ولا يثبت الالتقاط أصلاً. الآن يُنشئ جدولة جديدة ويُثبت الالتقاط الفعلي.
5. **دورة تصدير←استيراد**: التحقق أن `meta/counters/jobs/applicants/attempts/settings`
   تنجو حرفياً (سجل التدقيق يزيد سطراً واحداً مقصوداً).
6. **سلامة الدمج الجزئي**: لا تكرار في الاستمارات ولا في المحاولات.
