# فلاتر اختيار الوظائف — صفحة البطاقة

المكان: `apply.html`، خطوة الوظائف بعد إدخال بيانات الزبون. لا تغييرات على إصدار البطاقة أو أكوادها أو اعتماد الطلب.

- بحث متعدد الكلمات في عنوان الوظيفة وكودها والتخصص والمحافظة والمنطقة والدوام والوصف والمتطلبات العامة؛ تطبيع التشكيل والهمزات والأرقام العربية والفارسية.
- المحافظات العراقية الـ١٩، بما فيها حلبجة. المحافظة غير المذكورة لا تُخمن من المنطقة ولا تُنسب إلى بابل؛ تبقى الوظيفة ظاهرة عند عرض الكل. توحيد أسماء مثل أربيل/اربيل والقادسية/الديوانية وذي قار/ذيقار.
- المناطق مأخوذة من الإعلانات وتتبع المحافظة المختارة؛ تغيير المحافظة يمسح المنطقة القديمة.
- نوع الوظيفة، الدوام، الجنس المطلوب بالإعلان مع وظائف «لا فرق»، والحد الأدنى **لبداية الأجر الشهري المعلن** بالدينار. مدخلات الأجر غير الصالحة تُظهر تنبيهاً، لا نتائج مضللة.
- ترتيب مقترح يقدّم محافظة الزبون ثم الجنس المطابق أو غير المقيد، بلا إخفاء بقية الوظائف تلقائياً؛ أو ترتيب الأجر تصاعدياً/تنازلياً، أو الأحدث. الأجور غير المذكورة في نهاية ترتيبي الأجر. التعادل يحافظ على ترتيب المصدر.
- زر «وظائف محافظتي المناسبة لبياناتي» إجراء اختياري يمسح الفلاتر المتعارضة ثم يستخدم المحافظة والجنس المدخلين.
- عداد نتائج ومختارات، «مختاراتي فقط»، مسح الفلاتر، وحالة عدم وجود نتائج. التفاصيل الإضافية قابلة للطي؛ عمود واحد في الشاشات الصغيرة.
- الاختيارات تبقى عند تبديل أي فلتر أو مسحه. التذييل يتيح إلغاء وظيفة مختارة حتى لو أخفتها الفلاتر. التقديم الفعلي واستهلاك الفرص لا يحدثان إلا عبر خطوة الإتمام القائمة أصلاً.
- الفلاتر تعمل محلياً على `public_jobs`؛ لا قراءة لبيانات صاحب العمل الخاصة، ولا RPC كتابة أو تغيير في صلاحيات القاعدة.

## التحقق

`npm run test:job-filters`: DOM فعلي عبر jsdom ومدخلات/قوائم/أزرار الصفحة الفعلية، ببيانات وهمية وقراءة بطاقة وهمية. يغطي تقاطع الفلاتر، التطبيع، الفرز، الفلاتر الشخصية، الحقول الخبيثة، إتاحة التسميات، المحافظة المجهولة، الحالة الفارغة، حفظ الاختيارات وإزالتها وعدم حدوث نداء كتابة.

`npm run test:apply`: المسار الأصلي الكامل، اختيار فرصتين ثم المراجعة والإتمام والطباعة واستهلاك الفرص بالعدد الصحيح. اختبار الفلاتر مضاف إلى `npm run test:all`.

هذه اختبارات محلية، وليست نشرًا أو تحققاً من بطاقات الإنتاج. لا يلزم ترحيل قاعدة بيانات لهذه الميزة.
