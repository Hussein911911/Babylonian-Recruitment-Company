# تصميم الإشعارات حسب الأولوية — 2026-10-19

## التقسيم الجديد

| القسم | اللون | ما يظهر فيه |
|---|---|---|
| حرج | أحمر عنابي | الإشعارات المصنفة حرجة/انتهاء المدة، وأحداث حذف الوظائف أو بيانات التشغيل |
| مهم | كهرماني | طلبات وقرارات صاحب العمل، وأحداث الاسترجاع والتعطيل والحذف الأخرى المتاحة حسب صلاحية الحساب |
| الحجوزات | أزرق | أحداث تسجيل الحجوزات |
| عادي | أخضر هادئ | تحديثات العمل الروتينية وقرارات الشركة المسجلة |

- فلاتر مستقلة مع عدّاد لكل قسم، بالإضافة إلى «الكل» و«غير المقروء».
- داخل «الكل» و«غير المقروء»: الحرج ثم المهم ثم الحجوزات ثم العادي؛ والأحدث أولاً داخل كل قسم.
- فواصل بعناوين وأعداد، وشارة نصية على كل بطاقة؛ المعنى لا يعتمد على اللون وحده.
- غير المقروء داكن ومميز؛ المقروء فاتح من نفس عائلة اللون. القراءة لا تنقل الحرج إلى العادي.
- لون عدّاد الجرس يتبع أعلى أولوية غير مقروءة، ويعود للوضع المحايد بعد قراءة الجميع.
- ملخص واضح بعدد الإشعارات الحرجة غير المقروءة. لا وميض أو إزعاج متكرر.
- الشاشات القصيرة تدعم تمرير الدرج كاملاً حتى تبقى الأزرار والتذييل قابلة للوصول.

## المعنى والحدود

هذه أولوية **لحدث/إشعار** وليست نظام اعتماد أو إغلاق للحالات. قد يكون الإشعار تاريخياً؛ الحالة الفعلية تُراجع من «عرض التفاصيل». قراءة إشعار لا تثبت توظيفاً ولا تحل تعارضاً ولا تفرج عن حجز.

طلبات صاحب العمل تبقى بانتظار قرار الشركة، وتثبيت التوظيف يبقى من مساره الحالي. لم تتغير قواعد الفرص أو الحجز بعد 24 ساعة أو الطباعة أو الحسابات أو النسخ والاسترجاع.

المصدر هو بيانات Store الموجودة والمصرح بها؛ لا اتصال جديد ولا خدمة خارجية ولا تعديل في القاعدة. ما زالت الصفحة تعرض **أحدث 100 حدث متاح**، ثم ترتب هذه النافذة بحسب الأولوية. الأعداد ليست إحصاءً لكل الحالات الحرجة عبر كامل تاريخ الشركة.

حُفظت معرفات الأحداث القديمة كما هي، فلا تُصفّر حالة القراءة السابقة. بقي عزل حالة القراءة بحسب المشروع والحساب والدور والجهاز، وحفظ معرفات القراءة المشتقة فقط دون محتوى الإشعارات، وتنظيف المحتوى عند الخروج. أصل نوع الحدث `kind` لم يتغير؛ أضيف `section` للعرض فقط.

## التحقق

- **40** اختبار نموذج إشعارات، منها 8 اختبارات إضافية للتقسيم والرتب والخصوصية والمعرفات والاحتفاظ.
- **294** فحص Chromium معزول عند 320/375/768/1440، مع فحص نافذة قصيرة 375×420. تشمل الفحوص السابقة كاملة، والترتيب والعدادات والألوان والفلاتر، وتباين النص والشارات الفعلي ≥4.5:1 في الأقسام الأربعة للمقروء وغير المقروء، وعدم تغيير الأولوية عند القراءة، ولوحة المفاتيح والطباعة والحركة المخففة وعزل الحساب والخروج.
- كل طلبات الخلفية غير المحلية محظورة في فحص المتصفح؛ الجلسة والبيانات وهمية، وليس هذا فحص دخول إنتاجي.
- `npm run test:all` والبناء والنسخة الخفيفة وتجميع النشر نجحت. حدود الأداء الأصلية لم تزد؛ تدقيق المشروع 140 نجاحاً وصفر فشل وثلاثة تحذيرات معروفة سابقة.

التغييرات في `notifications.js` و`notifications.css` وجزء لوحة التحكم والملفات المبنية، مع تحديث جيل الكاش إلى v38. لم تُعدّل Store أو Auth أو قوالب البطاقة أو أي هجرة قاعدة بيانات. تُرفع للفرع الحالي فقط، **بدون دمج**.
