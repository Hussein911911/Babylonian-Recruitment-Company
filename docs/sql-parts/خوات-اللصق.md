# خوات اللصق — ورقة واحدة

> اطبع هذه الورقة أو أبقها مفتوحة. كل سطر = لصقة واحدة في SQL Editor.

## ⑴ جهّز البيانات (مرة واحدة)

```
1) افتح restore.html ← فكّ التشفير ← ينزل 1-schema.sql و 2-data.sql
2) ضع 2-data.sql بجانب package.json
3) node tools/split-sql.mjs 2-data.sql --out docs\sql-parts\data
```

---

## ⑵ السكيما — ٥ لصقات

افتح Supabase → SQL Editor → New query، والصق بالترتيب:

| ✓ | الملف |
|---|---|
| ☐ | `docs/sql-parts/schema/schema-part-01.sql` |
| ☐ | `docs/sql-parts/schema/schema-part-02.sql` |
| ☐ | `docs/sql-parts/schema/schema-part-03.sql` |
| ☐ | `docs/sql-parts/schema/schema-part-04.sql` |
| ☐ | `docs/sql-parts/schema/schema-part-05.sql` |

> ⏱ في الجزء ٥ سطر `select brc.archive_finished_cards();` قد ينتهي بمهلة.
> لو ظهر `statement timeout` فالجزء **نجح** — تابع.

---

## ⑶ البيانات — بالترتيب الرقمي

الملفات في `docs\sql-parts\data\` باسم `2-data-part-01.sql` … وهكذا.
الصقها **بالترتيب الرقمي** واحداً واحداً. العدد يختلف بحسب حجم بياناتك.

> ⚠️ الجزء الأول من البيانات فيه `TRUNCATE` — **يُفرّغ الجداول**.
> لا تلصقه على قاعدة فيها بيانات تريدها.

---

## ⑷ تحقّق

```sql
select 'jobs' as t, count(*) from brc.jobs
union all select 'applicants', count(*) from brc.applicants
union all select 'job_attempts', count(*) from brc.job_attempts
union all select 'audit_log', count(*) from brc.audit_log
union all select 'staff', count(*) from brc.staff
order by 1;
```

قارن بالأعداد المكتوبة أعلى `2-data-part-01.sql` في سطر «الأعداد».
