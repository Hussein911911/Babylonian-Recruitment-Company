# أزرار التنقل ولوحة مفاتيح الموبايل

- أزرار التالي والرجوع في خطوات البيانات والوظائف والمراجعة أكبر، وتبقى تحت المحتوى في العرض الطبيعي.
- عند التركيز على حقل وظهور تقلص واضح في مساحة العرض على شاشة لا تتجاوز 760px، ينتقل **شريط الأزرار الأصلي نفسه** إلى طبقة ثابتة خارج الصفحات المتحركة، فوق المساحة المحجوبة بلوحة المفاتيح.
- يستخدم `visualViewport.height/offsetTop` لحساب موضع لوحة المفاتيح العائمة فوق التخطيط، ويقبل أيضاً وضع تقلص تخطيط الصفحة في Android. عند غياب API يستفيد من تغير ارتفاع النافذة.
- لا يتم استنساخ الأزرار: أحداث النقر وحالة التعطيل وإخفاء الرجوع للبطاقة المثبتة تبقى كما هي. مساحة بديلة تحافظ على موضع المحتوى، ويُرفع الحقل عند الحاجة حتى لا تحجبه الأزرار.
- إغلاق الكيبورد أو تغيير الصفحة يعيد الشريط إلى موضعه الأصلي. التكبير اليدوي لا يعامل ككيبورد. الطبقة لا تظهر في الطباعة.

الملفات: `apply.html` و`assets/js/apply-navigation.js`. لا تغيير على بيانات البطاقة أو الفرص أو نداءات التقديم. الأصل الجديد مشمول بالتوزيع الآلي لمجلد assets وكاش v29.

`npm run test:apply-navigation`: تغييرات مصطنعة في VisualViewport عبر DOM فعلي للتحقق من الموضع والاستعادة، Android/iOS-style layouts، التكبير، تغيير الصفحة، fallback، أحداث النقر، التعطيل وبقاء زر الرجوع مخفياً. هذه محاكاة هندسية وليست اختباراً للوحة مفاتيح فعلية على جهاز iPhone/Android؛ سلوك لوحة المفاتيح يختلف باختلاف المتصفح وإعداداته.
