# تنظيف صفحة الدخول وخط IBM Plex — 2026-10-19

## التغيير

- إزالة سطر بيانات الدخول الافتراضية من جزء لوحة التحكم، وليس إخفاءه بـ CSS.
- إزالة مولّد تذكير الفريق الأصفر ومسار ملف قائمة التسليم من JavaScript المنشور؛ لا يظهر حتى في سيناريو الوضع الانتقالي الاختباري.
- إبقاء حقول الدخول والزر ورابط العودة وحالة الاتصال الفعلية ورسائل الخطأ المهمة.
- **لا تغيير لحماية الدخول:** `enforceAuth: true` و`users: []` كما كانا. لم تُعدّل Auth أو RLS أو وظيفة إدارة الموظفين أو صلاحيات القاعدة، ولم تُغيّر كلمات مرور حسابات الإنتاج. اختبارات منع الحساب المحلي ورفض تجاوز الصلاحيات تبقى كاملة.
- استبدال Tajawal بـ **IBM Plex Sans Arabic** في الموقع العام والتحقق ولوحة الموظفين والتقديم وبوابة صاحب العمل؛ أربعة أوزان حقيقية 400/500/600/700، عربية ولاتينية كاملة ومحلية، دون Google Fonts. العناوين الأثقل تطابق وزن Bold المتاح حسب اختيار المتصفح القياسي.
- حذف ملفات Tajawal التي لم تعد مستخدمة. بقيت ملفات Cairo وخطوط الطباعة والأكواد وقياسات البطاقة وقواعد العمل وتوقيت بغداد دون تغيير.
- كاش Service Worker إلى v40 وإعادة بناء النسخ الكاملة والخفيفة وتجميع النشر.
